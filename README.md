# **acalendar**

### **✨ Features**

* **Flexible Calendar Creation**: Easily define academic calendars with custom start and end dates.
* **Holiday Management**: Add, remove, and manage holidays, breaks, and non-instructional days.
* **Academic Week and Day Logic**: Determine if a given date is a weekday, weekend, or a specific academic day type.
* **Simple API**: A clean and intuitive interface for querying calendar information.

### **🚀 Installation**

acalendar is available on PyPI. You can install it using pip:

pip install acalendar

### **📖 Usage**

poetry run calendar --help

poetry run calendar -c calendars/cal_3530_25f.toml -hlv
